傻瓜切换说明
· DeepSeek / 通义千问 / 硅基流动 / OpenAI 兼容网关都使用各自的 API Key + base_url，选好供应商会自动填好地址，填 Key 与模型名即可。
· 本地 Ollama 无需 Key，先 ollama pull 模型再填模型名(如 qwen2.5:7b)。
